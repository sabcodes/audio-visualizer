WAVE 6 ASSET LIST
=================
Companion to 2026-10-26-wave-six-modes-design.md. No specs here, only what is needed.
Each line: [REQUIRED | OPTIONAL | NOT NEEDED] | kind (3D model, 3D animation, 2D image) | role (MAIN visual asset | PROP) | belongs to (mode id, wave 6 #)

-------------------------------------------------------------------------------
BATCH 1 (2026-10-26): NOTHING IS REQUIRED. All three modes can be built in code with WebGPU/TSL.
-------------------------------------------------------------------------------

OPTIONAL | 3D model | PROP | nightParlour (wave 6 #1)
  Upholstered armchairs: a squat leather club chair and a tall wingback with a round footstool.
  Why optional: soft, sagging fabric shapes are the hardest part of the room to make look right in code.
  Code version uses rounded boxes and bent planes; commission only if it looks stiff beside the reference.

OPTIONAL | 3D model | PROP | nightParlour (wave 6 #1)
  Gramophone with petal horn, and a stained-glass table lamp.
  Why optional: both are lathe shapes code handles well; only worth it if the detail looks thin.

OPTIONAL | 2D image | PROP | nightParlour (wave 6 #1)
  Fabric/wallpaper tile set (floral needlepoint, braided rug, faded damask wallpaper), seamless, 512-1024 px.
  Why optional: procedural patterns are planned; a painted tile set would read warmer.

NOT NEEDED | 3D model | MAIN | slotHall (wave 6 #2)
  Slot machines, stools, stanchions: low-poly by design, code is enough.

OPTIONAL | 2D image | PROP | slotHall (wave 6 #2)
  Low-res pixel textures (64-128 px): carpet starburst, wallpaper diamonds, reel symbols, "7" emblem.
  Why optional: procedural versions sampled with nearest filtering get close; hand-pixelled ones
  would be more authentic to the retro look.

NOT NEEDED | any | MAIN | windowGrid (wave 6 #3)
  Facade and windows are a grid of instanced quads plus a concrete shader.
